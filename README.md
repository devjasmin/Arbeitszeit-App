**Arbeitszeit-App**


**Ziel:** 
Die App soll meine Arbeitszeiten im Büro wieder geben. Wir haben keine Zeiterfassung und deshalb wollte ich eine bessere Lösung als eine Excel-Datei. 
Die App soll mir auch meine Zeiten ausdrucken können. 

**Tech Stack**

- **Frontend:** HTML5, CSS3
- **Logik:** JavaScript 
- **Datenbank:** Browser LocalStorage


**Aktueller Status & Roadmap (Work in Progress)**

Die App ist voll einsatzfähig, befindet sich jedoch in kontinuierlicher Weiterentwicklung. Folgende Features sind als nächste Meilensteine geplant:

- soll die Zeiten pro Monat ausdrucken können
